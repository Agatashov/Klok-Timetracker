# Klok brand kit

App icon: round 9 no. 3 "Heavy" (three progress-dot rings, no hands). Wordmark: lettering no. 6 (dot-matrix KLOK, stemless K). Palette is shared: rose, orange, yellow only.

- `app/macos/` Klok.iconset, AppIcon.icns, Xcode AppIcon.appiconset, Klok-1024.png. Sizes under 64 px use a simplified icon with fewer, larger dots.
- `app/menubar/` black template images (ghost dots at 30% alpha); set isTemplate = true.
- `web/` favicon.ico/.svg, PNG favicons, apple-touch-icon, 192/512 icons, maskable, 1024, OG image 1200x630, site.webmanifest, head-snippet.html.
- `wordmark/` SVG + PNG (2x): dark, light, white, black, no-grid, and an icon + wordmark lockup (dark).
- Compact wordmark (no ghost dots, heavier) for navigation bars under ~200 px wide; stem-K alternative where a plain K reads better.
- `source/` editable SVGs for every icon.

Colours: ground #121212, ghost #333, rose #bd5e73, orange #FF7A00, yellow #FFD23F, mint #33E28A, paper #F4F2EE.
